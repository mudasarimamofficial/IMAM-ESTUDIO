# Incident Response Protocol

- **Tier 1 (Soft halt):** Stop new operations, notify admins.
- **Tier 2 (Active purge):** Delete ephemeral data, force logouts.
- **Tier 3 (Full scrub):** Legal trigger - vault lock.
- **Access roles:** Super Admin, Founder only.
